## 🚀 Projetos de Cybersecurity

### 🛡️ NetSentinel — Network Reconnaissance & Security Toolkit

**Status: Em desenvolvimento / Planejamento**

Projeto pessoal desenvolvido em Python, com o objetivo de criar uma ferramenta de apoio a reconhecimento de redes e análise inicial de ativos.

**Funcionalidades planejadas:**
- Descoberta de hosts ativos
- Integração com Nmap
- Identificação de portas e serviços
- Inventário de ativos de rede
- Identificação de configurações potencialmente inseguras
- Geração de relatórios de reconhecimento
- Diferentes perfis de varredura

O NetSentinel representa minha evolução dos fundamentos de Python para o desenvolvimento de ferramentas voltadas à segurança ofensiva.
